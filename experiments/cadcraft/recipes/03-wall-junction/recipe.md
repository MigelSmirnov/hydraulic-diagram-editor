# 03 — Т-образное примыкание, BREAK + TRIM + BREAK

**Цель:** убрать разделяющие линии между несущей стеной и примыкающей перегородкой.

**Вход:** `host_inner_edge_handle`, `partition_handle`, две точки границ примыкания, реальные боковые грани перегородки, точки выбора удаляемых участков.

Для P01: `host_y=200`, `left_x=3520`, `right_x=3610`.

**Последовательность:**
1. Сохранить DXF и определить текущий handle внутренней грани несущей стены, проходящей через весь интервал примыкания.
2. `{"command":"break","params":{"handle":"${host_handle}","p1":[3520,200],"p2":[3610,200]}}`
3. Перечитать DXF: прежний handle может исчезнуть; проверить отсутствие любого отрезка несущей стены, перекрывающего интервал X=3520…3610 при Y=200.
4. Для отдельных граней перегородки, которые выступают за Y=200, использовать `trim` с режущей гранью и точкой `pick` на удаляемом участке:
```json
{"command":"trim","params":{"handle":"${left_face_handle}","pick":[3520,150],"edges":["${cutter_handle}"],"mode":"standard"}}
{"command":"trim","params":{"handle":"${right_face_handle}","pick":[3610,150],"edges":["${cutter_handle}"],"mode":"standard"}}
```
5. Если перегородка уже замкнута и её торец ещё присутствует, применить `break` к **актуальному** handle полилинии на точках концов торца. Не разрывать боковые грани.
6. Удалить временную режущую линию через `erase`.

**Проверки:** нет ни сегмента несущей стены, ни торца перегородки на интервале примыкания; боковые грани доходят до несущей стены; наружная граница не повреждена; не возникло случайных разрывов в углах.

**Особенность:** `BREAK` на закрытой полилинии может преобразовать её в открытую и заменить handle. Проверять результат по DXF-геометрии, а не по прежнему идентификатору. Для нескольких примыканий повторять поиск актуальной полилинии перед каждой операцией.
