# 01 — Наружные стены, PLINE + OFFSET

**Цель:** построить внешнюю границу и внутреннюю грань стены толщиной `t`, сохранив внешние габариты.

**Вход:** `outer_vertices` (по порядку, мм), `interior_point` (точка строго внутри), `t=200`.

**Команды CADCraft:**
```json
{"command":"layer.new","params":{"name":"EXTERIOR_200","current":true}}
{"command":"pline","params":{"vertices":[[0,0],[8382,0],[8382,4775],[0,4775]],"closed":true}}
{"command":"offset","params":{"handle":"${outer_handle}","distance":200,"side":[4191,2387]}}
```
Handle из ответа `pline` передаётся в `offset`. Точка `side` задаёт внутреннюю сторону, а не направление оси.

**Результат:** две замкнутые `LWPOLYLINE` с границами [0,0,8382,4775] и [200,200,8182,4575] в прямоугольном тесте.

**Проверки:** обе полилинии замкнуты; внутренний контур внутри наружного; отступ 200 мм; внешние размеры не изменились. Не использовать это упрощение для фасада с проёмами без отдельной обработки.
