# План квартиры по фото эскиза

Сценарий «фото распечатки с рукописными обмерами → чертёж».

```bash
python -m pip install 'ezdxf>=1.3,<2' 'matplotlib>=3.8,<4' 'shapely>=2,<3'
python experiments/cadcraft/sketch_plan/build_plan.py   # пишет в dist/sketch_plan/
```

Результат: `apartment_sketch_A3_1_50.dxf` (редактируемый, слои), `.pdf` (вектор, A3 альбомный,
точно 1:50), `.png`, `manifest.json`.

## Как устроено

1. `plan.json` — расшифровка эскиза в мм: стены прямоугольниками и полигонами, окна,
   размеры с подписями эскиза (`cm`), вопросы к эскизу.
2. `build_plan.py` объединяет стены (shapely), поэтому примыкания получаются без торцов,
   а проёмы — это промежутки между кусками стен.
3. Гейт перед экспортом: каждый размер из `dimensions` обязан совпасть с начерченным
   расстоянием, а его точки — лежать на грани стены. Несовпадение останавливает сборку.

## Правила расшифровки

- Подложка эскиза схематична. Где есть рукописный обмер, геометрия строится по нему;
  масштаб подложки (около 6,65 мм на пиксель фото) используется только там, где обмера нет.
- Размер, который не удалось согласовать с остальными, в чертёж не идёт: он записан в
  `questions` и отмечен на плане красным номером.
- Толщины стен не обмерялись, см. `thickness.note`.

## Ограничения

- Это черновик по эскизу, не обмерный чертёж: восемь вопросов в `plan.json` открыты.
- Направления открывания дверей и мебель не начерчены.
- Собрано на Python (ezdxf), без CADCraft: рецепты `execute pline/offset/break` сюда не
  подключены. Перенос в CADCraft MCP — отдельный шаг, `plan.json` годится как вход.
