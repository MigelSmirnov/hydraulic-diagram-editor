# CADCraft — индекс операций

Опора для сценариев: что агент может вызвать и насколько этому можно верить.
Сценарии и граф собираются только из строк «проверено нами».

Источник: `storytold/cadcraft` @ `e86d895` (2026-10-25). На нём локально прошли все тесты из
статуса «проверено нами», включая слои и библиотеку блоков. CI собирает ветку `main` без пина,
поэтому прогон #71 мог идти на более раннем коммите. Пин коммита — критерий продвижения
в `CHECKPOINT.md`.

Статусы:
- **проверено нами** — тест в `experiments/cadcraft/`, зелёный в CI, проверка по DXF;
- **создаётся** — команда отработала в тесте, но результат проверен только счётом сущностей;
- **есть в CADCraft** — есть в каталоге команд (у части команд есть свои unit-тесты в upstream), нашим тестом не проверено;
- **нет** — в CADCraft отсутствует.

Все вызовы: MCP-инструмент `execute {command, params}`, если не указано иное.
Полный каталог с параметрами: инструмент `list_commands {filter?}`.

## Слои

Проверено на готовом чертеже `apartment_p01_integrated.dxf`, тест `test_layer_states.py`
(локально, CADCraft `e86d895`).

| Операция | Команда | Статус |
|---|---|---|
| Создать / сделать текущим | `layer.new {name, color?, linetype?, lineweight?, current?}`, `layer.current {name}` | проверено нами |
| Выключить / заморозить / не печатать | `layer.set {name, on?, frozen?, plot?}` | проверено нами: скрытые слои не попадают в PNG, `plot:false` остаётся на экране, но не печатается |
| Цвет слоя в печати | `layer.new {color}` | проверено нами (синяя сантехника в PNG) |
| Блокировать | `layer.set {name, locked}` | проверено нами, см. ловушку 2 |
| Сохранить набор видимости («сантехника», «электрика») | `layerstate.save {name}` | проверено нами |
| Восстановить набор | `layerstate.restore {name}` | проверено нами |
| Наборы и активная видимость сохраняются в DXF | `save` → `open` → `layerstate.list` | проверено нами |
| Список наборов | `layerstate.list` | проверено нами |
| Удаление / переименование наборов | `layerstate.delete`, `.rename` | есть в CADCraft |
| Изолировать слой объекта / вернуть | `layiso {handles}` / `layuniso` | есть в CADCraft |
| Всё включить / разморозить | `layon`, `laythw` | есть в CADCraft |
| Перенести объекты на слой / слить слои | `laymch {handles, layer}`, `laymrg {from, to}` | есть в CADCraft |
| Кто использует слой / блок | `usage {type?}` | есть в CADCraft |

Ловушки:
1. `query_entities {layer}` возвращает объекты и на выключенных, и на замороженных слоях,
   признака видимости в ответе нет. Видимость проверять через `layer` (`on`, `frozen`).
2. `erase` объекта на заблокированном слое **не ошибка**: ответ `{"erased": 0}`.
   Сценарий обязан проверять счётчик.
3. Текущий слой заморозить нельзя (ошибка `cannot freeze the current layer`):
   сначала `layer.current` на другой слой.
4. После `open` текущим остаётся слой, который был текущим при сохранении
   (в готовом чертеже это `ELECTRICAL_SOCKET`). Перед рисованием всегда задавать текущий слой явно.

| Вставить блок **из файла** библиотеки | `insert {name, file, at, rotation, attribs}` | проверено нами: чертёж блока не знал, INSERT определил его из файла | `test_block_library.py` |
| Атрибуты блока (марка, ширина) | `attdef {tag, prompt, default, at, height}`, `insert … attribs:{TAG: value}`, поиск `find_text {contains}` | проверено нами | `test_block_library.py` |
| Подменить блок во всех вставках | `blockreplace` | есть в CADCraft |  |
| Подложка из другого чертежа (xref) | `xattach {path, overlay?, at?}` | есть в CADCraft |  |
| Динамический блок: **читать и менять** готовый | `blocks.dynamic`, `blocks.reference.set`, `blocks.reference.grip` | есть в CADCraft |  |
| Динамический блок: **создать** | — | **нет** (upstream `docs/gaps.md`, F3: нет авторинга параметров и действий) |  |

Правило библиотеки: один статический блок на типоразмер (`WIN_900_W200`), один файл DXF
на блок. Соглашение для проёмов: база в углу по наружной грани, локальная X вдоль стены,
локальная +Y от наружной грани к внутренней.

Ловушки:
1. `rotation` вращает вокруг базовой точки: +90 переводит локальную +Y в мировую −X.
   Окно на левой стене (наружная грань x=0) — `rotation:-90`, база в верхнем конце проёма.
   С `rotation:90` в той же точке окно уходит наружу из стены.
2. `insert` не режет стену: линии граней проходят сквозь окно. Проём — отдельный шаг
   (BREAK обеих граней на ширину проёма, ветвь A1/A2 рецепта 03), его ещё нужно проверить.
